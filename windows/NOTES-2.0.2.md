# Siloé Stream 2.0.2 — Design « Conducteur »

- **À L'ÉCRAN** (en or) : ce qu'on voit dans l'église. Un clic dans le programme ou sur une diapositive l'y met tout de suite.
- **ENVOYER À L'ANTENNE** : le gros bouton bordeaux entre les deux écrans (touche S). Ce qui est à l'écran part sur YouTube, Zoom et MyStream, et l'antenne le suit. Le bouton le dit (« L'ANTENNE SUIT L'ÉCRAN ») ; un clic de plus, ou M, ramène l'antenne sur sa source principale.
- **À L'ANTENNE** (en rouge) : ce que reçoivent YouTube, Zoom et MyStream.
- **Chaque écran a sa source principale** (le menu sous l'écran : caméra, image, écran principal, noir…) et son bouton **Revenir**, qui ne ramène que cet écran (Échap pour l'écran de l'église, M pour l'antenne).
- Le gros bouton **SUIVANT** dit ce qui vient (« Jean 3:17 »). La zone « Ensuite » séparée est retirée ; le centre montre le conducteur, toutes les diapositives du culte.
- Couleurs « Conducteur » : sombre chaud, or pour l'écran, rouge pour l'antenne, bordeaux pour l'envoi. Le thème clair suit les mêmes couleurs de sens.
