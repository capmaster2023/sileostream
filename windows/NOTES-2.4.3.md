# Siloé Stream 2.4.3 — Zoom dans l'église

- Son › **Dans l'église** : nouvelle case **« Le son de Zoom (les personnes à distance) »**. Le son de Zoom est capté directement (sans rien changer dans Zoom) et joué sur les haut-parleurs choisis juste au-dessus, avec son propre **curseur de volume**.
- Il n'est ni enregistré ni renvoyé vers Zoom.
- Conseil affiché : dans Zoom › Paramètres › Audio, choisir comme haut-parleur une autre sortie que celle de l'église (par exemple « CABLE Input »), sinon on l'entend deux fois. En cas d'écho chez les personnes à distance, baisser le volume.
- Site : page **/installer/** qui enregistre le jeton GitHub et l'identifiant Google sur Hostinger.
