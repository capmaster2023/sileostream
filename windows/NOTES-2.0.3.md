# Siloé Stream 2.0.3 — MyVirtualCam, une caméra officielle

- **MyVirtualCam** (l'image de MyStream : ce que voient YouTube et Zoom) est maintenant une caméra officielle de Siloé Stream, comme l'OBS Virtual Camera dans OBS. Elle est proposée partout où l'on choisit une caméra :
  - Médias › Ajouter une source › **Périphérique de capture vidéo** : en tête de liste ;
  - Médias › Ajouter une source : juste après « Périphérique de capture vidéo » ;
  - Duo : le menu **Choisir… / Changer…** de chaque élément ;
  - la **source principale** de l'écran (À L'ÉCRAN) ;
  - le programme : **Média de la bibliothèque** et **Écran principal**.
- Pas besoin de l'ajouter aux médias d'abord : au premier choix, elle est installée si besoin (Windows demande l'autorisation), puis ajoutée aux médias, une seule fois.
- Comme avant, elle ne repart jamais à l'antenne : MyStream ne se filme pas lui-même.
