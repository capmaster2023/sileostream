# Siloé Stream 1.9.4 — La connexion Google de l'application Android

- **Application Android** : « Se connecter avec Google » passe maintenant par les identifiants Google prévus pour une
  application Android (un client Android pour l'application, le client Web du site pour le serveur des comptes).
  C'est elle qui permet de créer son église, d'ajouter les membres et d'entrer sans code QR.
- Logiciel Windows : rien ne change depuis la 1.9.3 (connexion Google par siloestream.tech, pages par rôle).
