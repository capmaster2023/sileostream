# Siloé Stream 1.9.2 — Les mises à jour arrivent par siloestream.tech

- **Nouveau site** : Siloé Stream se télécharge sur **siloestream.tech** (installateur Windows, version portable et
  application Android).
- **Mises à jour** : le logiciel (Réglages › Mise à jour) et l'application Android cherchent maintenant les nouvelles
  versions sur siloestream.tech.
- **À installer une fois à la main**, sur le PC puis sur les téléphones : les versions précédentes ne connaissent pas
  encore le site. Ensuite, chaque nouvelle version est proposée toute seule. Chants, Bibles, réglages et téléphones
  jumelés sont gardés.
- **Un seul nom** : les derniers « MyChurch » visibles (relais, application Android) deviennent Siloé Stream.
- Serveur (VPS) : le relais s'appelle maintenant « siloestream-relais » ; une réinstallation retire l'ancien service.
