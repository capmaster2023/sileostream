# Siloé Stream 2.1.0 — Commencer le culte

- **Commencer le culte** (le bouton vert en haut) : un clic vérifie tout ce qu'il faut pour le culte, lance l'enregistrement, puis montre le bilan :
  - **Projecteur** : l'écran de l'église est allumé (sinon : Ouvrir) ;
  - **YouTube** : le compte est relié (ou la clé de stream enregistrée), Internet répond (sinon : Relier) ;
  - **Son** : les micros et la table de mixage sont branchés et pas coupés ; le niveau s'affiche en direct (« On entend : Micro du pasteur · bon niveau ») ;
  - **Caméras** : chaque caméra des médias est branchée (webcam, carte de capture, téléphone MyCam, caméra Sony) ;
  - **Enregistrement** : le culte s'enregistre dans le dossier choisi (le premier enregistrement de la page Son : MP3, ou vidéo si vous l'avez réglé ainsi).
  Pendant l'enregistrement, le bouton devient rouge, **Terminer le culte** : l'enregistrement s'arrête et le fichier est gardé.
- **Réglages › Son › Dossier des enregistrements** : nouveau bouton **Choisir…**. Les enregistrements qui étaient dans l'ancien dossier par défaut suivent.
- **Médias** : « + Ajouter un média » ne garde que les médias (texte, images, vidéos, fenêtre, Duo). Juste en dessous, **+ Ajouter un périphérique vidéo** : MyVirtualCam d'abord, puis chaque webcam ou carte de capture branchée (un clic l'ajoute), le téléphone MyCam et la caméra Sony par Wi-Fi.
