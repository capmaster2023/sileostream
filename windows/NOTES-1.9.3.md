# Siloé Stream 1.9.3 — Se connecter au logiciel avec Google

- **Connexion Google sur le PC** : bouton **Compte** (barre de gauche) › Se connecter avec Google. La page
  siloestream.tech/connexion s'ouvre dans le navigateur ; une fois le compte choisi, Siloé Stream s'ouvre avec les pages
  de votre rôle.
- **Chacun son rôle** (les mêmes que dans l'application Android) :
  - **Admin** : tout, et les membres de l'église ;
  - **Versets** : seulement la Bible ;
  - **Chants** : seulement les chants ;
  - **Affichage** (nouveau) : ce qui est affiché dans l'église et sur Zoom : le Culte, les Médias, le Duo, la projection
    et l'écran de scène ;
  - **Caméraman** : MyCam, sur le téléphone.
- **Les membres** : Réglages › Église et comptes. L'admin ajoute quelqu'un par son Gmail et choisit son rôle, le change ou
  le retire. Il peut aussi relier ce PC à son église, ou en créer une, sans passer par le téléphone.
- **Connexion obligatoire** : dans la même section, l'admin peut demander à chacun de se connecter au démarrage. Sinon,
  sans compte connecté, le logiciel reste entier, comme avant. Sans Internet, le dernier compte connecté garde son rôle.
- Serveur (VPS) : relancez une fois l'installation du relais pour le rôle Affichage (la commande est en tête de
  relais/installer.sh, avec le jeton GitHub en lecture seule).
